# Архитектура

Пакет `true_fps` не зависит от структуры приложения-потребителя.

| Модуль | Ответственность |
| --- | --- |
| `__init__.py` | Явные экспорты публичных классов, функции и исключений |
| `detector.py` | Проверка пути видео, чтение метаданных, обработка окон и возврат результата |
| `ffprobe.py` | Поиск исполняемого файла, subprocess с таймаутом, проверка JSON |
| `measurement.py` | Чистые вычисления окон, FPS и относительного разброса |
| `result.py` | Неизменяемые типизированные данные результата и статусы |
| `exceptions.py` | Иерархия ошибок внешних ресурсов |
| `video_tools.py` | Поиск запускающихся ffmpeg/ffprobe: локальный каталог, затем PATH |
| `installer.py` | Загрузка сборки FFmpeg, атомарная установка и проверка комплекта |
| `py.typed` | Маркер PEP 561 для потребителей типизированного пакета |

Детектор хранит адаптер ffprobe и порог согласованности. Состояние видео между
вызовами не сохраняется. Каждый вызов запускает до четырёх процессов: один для
метаданных, затем по одному для каждого из трёх окон. Импорт не создаёт детектор.
Нет фабрик, систем стратегий и глобального логирования. Установка инструментов
выполняется только явным вызовом `ensure_video_tools`/`install_video_tools`;
детектор сам ничего не ставит.

Тесты подменяют границу `subprocess.run`, сохраняя реальную оркестрацию,
разбор JSON и вычисления. Интеграционные проверки создают небольшие видео
во временном каталоге; двоичные инструменты и видеоданные не входят в пакет.
