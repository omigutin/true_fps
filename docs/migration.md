# Перенос из fps.zip

Перед реализацией прочитаны все 11 файлов предоставленного архива. Проект
реализует библиотечный API, а не совместимую замену всех старых имён.

| Исходник | Решение |
| --- | --- |
| `real_fps_probe.py` | Окна около 10/50/90%, ограничение min(5, duration/6), формула интервалов, взвешивание и порог 1% перенесены в `measurement.py`; процесс и JSON — в `ffprobe.py` |
| `fps_detector.py` | Оркестрация переписана в `detector.py`, без пользовательского FPS, OpenCV и стороннего логирования |
| `fps_result.py` | Вместо выбора источника — FPS, статус согласованности, причина и диагностика окон в `result.py` |
| `header_probe.py` | Не перенесён; заголовочные FPS, размеры и число кадров остаются в приложении |
| `tool_locator.py` | Целиком не перенесён; только независимый поиск явного инструмента или PATH |
| `video_tools_guard.py` | Не перенесён; установка инструментов остаётся обязанностью потребителя |
| `fps_strategy.py`, `ffprobe_fps_strategy.py`, `mediainfo_fps_strategy.py`, `opencv_fps_strategy.py` | Пустые устаревшие стратегии не перенесены |
| `__init__.py` | Создан заново с явным публичным API |

Исправленные особенности исходного алгоритма:

- Удалено фактическое округление до четырёх знаков.
- Одно окно больше не получает признак подтверждённой согласованности.
- Невалидные и повторяющиеся метки не скрываются фильтрацией и сортировкой.
- Ошибки запуска, чтения, JSON и таймауты стали различимыми исключениями.
- Неверный явный путь ffprobe больше не заменяется другим инструментом.
- Относительный конец `START%+L` заменён абсолютным `START%END`; ранний seek
  отфильтровывается по реальным меткам, чтобы окна не описывали один участок.

В NeuroTestLab остаются выбор пользовательского FPS, настройки `config.env`,
UI, OpenCV-диагностика и перекодирование. Само приложение не изменялось.
Зависимостей `src.pc_common.*`, неявного `.runtime_tools` и поиска корня репозитория
в новом пакете нет. Интеграция нового API в приложение — отдельная задача.

Пакет, дистрибутив и каталог приведены к уточнённому имени `true_fps`:
`from true_fps import FpsDetector`, исходники `src/true_fps/`.
