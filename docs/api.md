# Публичный API

Все публичные имена импортируются из `true_fps`.

## FpsDetector

```python
FpsDetector(
    ffprobe_path: str | Path | None = None,
    *,
    timeout: float = 30.0,
    consistency_threshold: float = 0.01,
)
```

- `ffprobe_path`: явный путь или имя команды; `None` ищет `ffprobe` в системном
  PATH. Строка с разделителем — путь; строка без разделителя — команда из PATH.
  `Path` всегда трактуется как путь относительно текущего каталога. Неверный
  явный инструмент не заменяется системным. Пустая строка недопустима.
- `timeout`: положительное конечное число секунд для **одного** вызова, не для
  всего измерения. Максимум четыре вызова; накладные расходы не входят в таймаут.
- `consistency_threshold`: конечное неотрицательное число, в долях единицы.
  `0` требует точного совпадения вычисленных значений, включая погрешность float.
- `ffprobe_path` (свойство): фактически выбранный абсолютный `Path`.
- `detect(video_path: str | Path) -> FpsResult`: измеряет файл, повторное
  использование экземпляра допустимо. Путь передаётся subprocess отдельным
  аргументом, кириллица и пробелы поддерживаются, оболочка не используется.

Функция `detect_fps(video_path, ffprobe_path=None, *, timeout=30.0,
consistency_threshold=0.01)` создаёт детектор и вызывает `detect`.

## FpsResult

Неизменяемая dataclass:

| Поле или свойство | Тип и смысл |
| --- | --- |
| `fps` | `float \| None`: оценка, без округления, независимо от статуса |
| `status` | `FpsStatus`: `CONSISTENT`, `INCONSISTENT`, `INSUFFICIENT_DATA` |
| `duration_seconds` | `float \| None`: положительная конечная длительность контейнера |
| `windows` | `tuple[WindowMeasurement, ...]`: все обработанные окна |
| `relative_spread` | `float \| None`: относительный разброс; для <2 окон отсутствует |
| `reason` | `str`: пояснение статуса, включая число согласованных окон |
| `usable_window_count` | `int`: число окон, участвовавших в вычислении |
| `is_consistent` | `bool`: статус равен `CONSISTENT`, пригодны хотя бы два окна |

`FpsStatus` наследует `str` и `Enum`; значения для сериализации — `consistent`,
`inconsistent`, `insufficient_data`.

## WindowMeasurement

Неизменяемая dataclass: `start_seconds`, `end_seconds` — запрошенные границы
в абсолютной временной шкале контейнера; `sample_count` — число конечных меток
внутри границ; `invalid_count` — число отсутствующих/невалидных меток среди всех
кадров ответа; `first_timestamp`, `last_timestamp` — фактические крайние метки
или `None`; `fps` — оценка пригодного окна либо `None`; `reason` — причина
отклонения либо `None`.

Свойства `interval_count` и `elapsed_seconds` возвращают соответственно `n - 1`
и разность крайних меток для пригодного окна; для отклонённого — ноль. Служебные
модули `measurement` и `ffprobe` не входят в стабильный публичный API.

## Политика ошибок

| Ситуация | Результат |
| --- | --- |
| Некорректный параметр Python | `TypeError` или `ValueError` |
| Неверный, нечитаемый путь видео или каталог | `VideoPathError` |
| Инструмент не найден или не запускается | `FfprobeNotFoundError` |
| Нет видеопотока, ошибка чтения, ненулевой код, stderr уровня error или неверный JSON | `VideoReadError` |
| Таймаут процесса | `FfprobeTimeoutError`, наследник `VideoReadError` |
| Нет длительности, пригодных меток или пригодно только одно окно | `FpsResult` со статусом `INSUFFICIENT_DATA` |
| Разброс выше порога | `FpsResult` с FPS и статусом `INCONSISTENT` |

`TrueFpsError` объединяет ошибки инструмента и файлов, но не ошибки аргументов.
Технические сбои не подавляются даже после успешного чтения предыдущих окон.
